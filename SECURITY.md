# Security Policy

## Supported Versions

Security updates are provided for the latest version of this project.

| Version | Supported |
| ------- | --------- |
| Latest  | Yes       |
| Older versions | No  |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, report them privately using GitHub’s **Report a vulnerability** feature under the repository’s **Security** tab.

Include:

- A clear description of the vulnerability
- Steps to reproduce it
- Potential impact
- Suggested remediation, if available

You may expect an acknowledgment within 7 days. We will investigate valid reports and provide updates as appropriate.

## Security Practices

- Keep dependencies updated.
- Do not commit passwords, API keys, or other secrets.
- Use environment variables for sensitive configuration.
- Review pull requests for security issues.
- Report suspicious activity responsibly.

Thank you for helping keep this project secure.
